# MediPencil · Päivän kuulumiset

**오늘의 안부 — 돌봄 루프형 가족 상황판**

가족의 질문을 기존 돌봄 대화와 기록에 연결하고, 사람이 확인한 내용을 허용된 범위에서 이해하기 쉽게 전달합니다.

## 현재 작업: PoC 제작 → 온라인 검토 → 피드백 → 명세 재확정

**[PoC 제작·사용 검증 계획 — Codex 시작점](docs/poc/README.md)** · **[AGENTS.md](AGENTS.md)**

2026-10-03 사용자 결정 D-11에 따라, 출국 전에 먼저 작동 PoC를 만들고 온라인 지원팀과 사용 검증을 진행합니다. 기존 상세명세 전체를 바로 구현하거나, 검증 전 또 다른 최종명세를 작성하지 않습니다.

| 단계 | 목표 |
| --- | --- |
| PoC 제작 | 독립 합성자료로 가족 질문→직원 확인→기록 승인→발행→가족 열람을 실제 서버·DB에 연결 |
| 온라인 지원팀 검토 | 서로 다른 세션에서 직접 사용하고 이해도·불편·오류·권한·엔진 처리 결과 확인 |
| 피드백·재시험 | 문제를 FB-ID로 기록하고 수정 전후와 재현 결과 비교 |
| 명세 재확정 | 유지/변경/보류/제외할 요구를 합의한 뒤 다음 상세명세 작성·사용자 승인 |

main의 지침 등록 당시 상태는 READY_FOR_CODEX/NOT_RUN입니다. 로컬의 기존 구현을 보존하고 `poc/remote-validation`에서 재사용합니다. 최신 실행 결과는 [PoC 검증 기록](docs/poc/validation-log.md)을 따릅니다. 지원팀 피드백과 후속 명세는 아직 AFTER_FEEDBACK입니다.

Codex는 PC-00부터 출발점과 기존 코드를 확인하고 PC-01의 직접 입력 작동 루프를 먼저 만듭니다. 실제 STT/LLM은 확인된 연결부만 사용합니다. 모의 결과와 실제 처리를 구별하고, 공유 서버·배포 권한이 없으면 로컬 검증까지 진행한 뒤 배포 대기 사항을 보고합니다. 실제 기록은 작업 시작 후 `docs/poc/validation-log.md`에 남깁니다.

## 로컬 검토 실행

```bash
npm --prefix apps/web run build
.venv/bin/python tools/dev/run_demo.py --poc --port 8767
```

PoC 모드는 설치된 AI 설정을 읽지 않고 직접 입력으로 시작합니다. [한국어 검토 안내](docs/poc/review-guide.md)와 [기존 설치 안내](docs/development/runbook.md)를 참고합니다. 공유 환경 배포·지원팀 실제 피드백은 별도이며 아직 완료하지 않았습니다.

## PoC 범위와 유지할 원칙

화면 1~5의 역할과 `가족 질문 → 직원 질문 큐 → 돌봄 대화/입력 → 수정·승인 기록 → 근거·권한이 적용된 가족 답변`을 검증합니다. 화면 6 사전문진, 전체 다국어, 스트리밍, 상용 회원가입·예약·알림, 실제 EMR 연동은 지금 만들지 않습니다.

근거 없는 좌우·기간·상태를 추가하지 않습니다. 계획은 실행 확인과, 답변 후보는 질문 완료와, 음성 삭제 요청은 실제 삭제 성공과 구별합니다. 승인·동의·공개 범위는 실제 서버에서 확인하고 비공개 원문을 브라우저에 먼저 보내지 않습니다.

## 대회 관련 확인은 별도

**내부 PoC 제작 요청은 대회 사전제작·반입·재사용 허가가 아닙니다.** PoC가 동일 과제의 사전 구현으로 판단될 위험은 남아 있습니다. 내부용·별도 브랜치·합성자료라는 이유만으로 예외라고 주장하지 않습니다. 주최 측 확인과 실제 반입 범위 신고, 작성 시점·기여 기록을 유지하며, 미확인 PoC를 자동으로 출품 코드에 병합하거나 행사 중 만든 것으로 표시하지 않습니다.

등록 팀원 외 온라인 지원인력이 대회용 코드·시험에 기여할 수 있는 범위도 별도로 확인합니다. 내부 사용성 의견과 대회 제작 기여를 구분합니다. 최신 확인 범위와 질문은 [PoC 계획 §8](docs/poc/README.md)에 있습니다.

## 공개 저장소의 데이터 경계

PoC에는 Veil.AI에서 유래하지 않은 독립 합성자료만 사용합니다. 실제 환자·입주자 정보, 실제 돌봄 음성, Veil.AI 원본·복제본·파생물, 비공개 엔진 소스, API 키·토큰·비밀번호, 검토자 개인정보·비공개 피드백 원본을 저장소·CI·모델 입력에 넣지 않습니다.

공유 배포에는 승인된 서버와 접근 제한이 필요합니다. 공개 저장소명이나 브랜치는 접근 통제·데이터 사용권·대회 허가를 대신하지 않습니다. 기존 회사·제품의 소유권·사용권이나 저장소 공개 설정은 이번 작업에서 변경하지 않았으며, 새 오픈소스 라이선스·제3자 데이터 재배포 권한을 부여하지 않습니다.
