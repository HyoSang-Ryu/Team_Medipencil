# MediPencil · Päivän kuulumiset

**오늘의 안부 — 돌봄 루프형 가족 상황판**

가족의 질문을 기존 돌봄 대화와 기록에 연결하고, 사람이 확인한 내용을 허용된 범위에서 이해하기 쉽게 전달합니다.

## 현재 로컬 구현 (2026-10-03)

사용자 후속 지시로 직접 입력 기반의 서버·DB·화면1~5 돌봄 루프를 구현했습니다. 실제 STT/LLM 및 Veil 연동은 미설정이며, FI 전문가 검수는 미완료입니다. 아래 설계 등록 당시 상태와 현재 실행 증빙은 구분합니다.

- [설치·실행·중지·재시작·정리](docs/development/runbook.md)
- [실제 명령·결과·커밋과 남은 제한](docs/development/progress.md)
- [T-01~T-10 검증 대응표](docs/development/acceptance-results.md)

```bash
npm --prefix apps/web run build
.venv/bin/python tools/dev/run_demo.py --port 8767
```

의존성 설치 및 Node22 선택은 runbook을 따릅니다. 로컬 주소는 `http://127.0.0.1:8767`입니다. 외부 공개 배포·주최 측 허용·실제 AI 검증을 완료했다고 뜻하지 않습니다.

개발명세는 `SPEC_READY`입니다. 기본 구현 조합은 **FastAPI + SQLite + React/TypeScript/Vite**로 구체화했으며 실제 STT·LLM 엔진은 확인 후 adapter에 연결합니다. 이것은 기존 엔진의 동작 확인이나 애플리케이션 구현 완료가 아닙니다.

Codex는 AGENTS.md와 개발명세를 읽고 P-00에서 현재 저장소·실행 단계를 확인합니다. **사전 준비와 과제 전용 현장 구현의 경계는 유지**하며, 허용 단계가 열린 뒤 C-01~C-12를 순서대로 수행합니다. 실제 실행 결과는 `docs/development/progress.md`에 별도로 남기고, 미실행·fixture·실엔진 검증을 구분합니다.

## 범위

Challenge 2의 **2.2 가족을 위한 상황판**을 중심으로 합니다. 핵심은 화면 1~5와 `가족 질문 → 직원 질문 큐 → 돌봄 대화 → 수정·승인 기록 → 근거·권한이 적용된 가족 답변`입니다. 화면 6(2.1 사전문진), 전체 다국어 화면, 실시간 스트리밍 전사는 핵심 검증 후 선택입니다.

R2 보정은 목업과 출력 예시에 직접 반영했습니다. 근거 없는 좌우·기간을 제거하고, 답변 후보와 완료 상태, 음성 삭제 정책과 실제 삭제 결과를 분리했습니다.

## 개발자가 먼저 확인할 곳

설계 문서의 **§5 화면**, **§6.2~6.5 객체·발행·상태·구현 계약**, **§7~9 데이터·동의·사전 제작 경계**, **§12 T-01~T-10 검증 기준**, **§15 결정·확인 과제**, **별첨 D 전후 비교**를 순서대로 읽습니다.

설계 확정은 과제 전용 구현을 행사 전에 완료하라는 지시가 아닙니다. 기존 자산과 행사 중 구현분을 구분하고, 실제 출발점을 보존·신고합니다. 외부 확인 사항 Q-01~Q-04와 실행 방식·담당자 결정은 문서에 표시된 상태로 유지합니다.

## 공개 저장소의 데이터 경계

여기에는 설계 문서와 독립 합성 예시·개발 코드·검증 요약만 둡니다. 실제 환자·입주자 정보, Veil.AI 원본·복제본·파생 데이터, 음성, 비공개 엔진 소스, API 키·토큰·비밀번호는 등록하지 않습니다. SVG는 구현 완료 화면이 아닌 설계 목업입니다.

기존 회사·제품의 소유권이나 사용권은 이 저장소명으로 변경되지 않습니다. 별도의 오픈소스 라이선스나 제3자 데이터 재배포 권한을 부여하지 않습니다.
