## 1. 확정 기준

사용자의 “제안대로 하고 최종 설계안으로 확정해서 문서로 만들고 GitHub에 등록” 요청에 따라 v1.1을 기획·설계 기준본으로 채택합니다. v1.0의 15개 장과 기존 별첨, 돌봄 루프, 화면 1~5의 핵심 범위를 유지하고 R2 보정과 구현 계약을 반영합니다. 화면 6(2.1 사전문진)은 핵심 루프 검증 후 선택입니다.

- [최종 확정 설계안 v1.1](medipencil-final-design-v1.1.md)
- [설계용 구조도와 보정된 SVG 목업 9개](assets/)

이번 작업 시작 시 main에 있던 v1.1 Markdown과 SVG 기준본을 읽어 R2 반영 내용을 확인했습니다. 그 기준과 범위·상태·핵심 문구를 맞춘 Word 배포본을 작성하고, 이 확정·배포 기록과 README 연결을 추가합니다. 기존 설계 기준본이나 애플리케이션 코드를 임의로 교체하는 작업이 아닙니다.

| 구분 | 확정 상태 | 의미 |
| --- | --- | --- |
| 기획·설계 기준선 | DESIGN_APPROVED | 사용자 지시에 따라 v1.1 채택 |
| R2 문서 보정 | DOCUMENT_CORRECTED | 본문·목업 이미지·출력 구조에 반영 |
| 애플리케이션 구현 | NOT_IMPLEMENTED | 이번 작업에서 서비스 소스 구현·배포하지 않음 |

설계 확정은 구현 완료, 임상 검증, 주최 측 승인, 데이터 이용 허가 또는 법률 요건 충족을 뜻하지 않습니다.

Word의 본문·표·목업·스키마를 대조하고 최종 렌더링 33쪽을 시각적으로 확인했습니다. R2 대상 이미지의 글자도 실제 교체했으며, 문서 안의 4개 JSON 설명 예시는 문법 파싱을 확인했습니다. 문서 패키지에서 추적 변경·주석이 없는 것과 원본 입력의 SHA-256 유지도 확인했습니다.

이 검수는 **문서 품질 검사**입니다. 애플리케이션 T-01~T-10, STT·LLM 성능, 서버 권한 차단, 실제 음성 삭제가 통과했다는 증빙으로 사용하지 않습니다.

## 5. 이후 작업의 기준

개발자는 최종 설계안의 §5 화면, §6 객체·상태·발행 계약, §7~9 데이터·동의·사전 제작 경계, §12 검증 기준, §15 결정·확인 과제를 기준으로 상세 구현합니다. 과제 전용 기능의 구현 시점은 기존 사전 준비/행사 중 제작 경계를 따릅니다. 이번 등록에는 실행 가능한 과제 전용 코드·합성 음성·Veil.AI 데이터가 포함되지 않습니다.

발표 담당과 실제 STT·LLM 조합은 D-05·D-06에서 결정합니다. Q-01 사전 제작물, Q-02 외부 API·파생물·보관·공개, Q-03 기존 엔진·권리·삭제·담당, Q-04 실제 돌봄 업무·권한·핀란드어는 미결로 유지합니다. 공개 규정에 없는 예외를 내부 설계 확정만으로 허용하지 않습니다.

공개 저장소에는 실제 환자·입주자 자료, Veil.AI 원본·복제본·파생물, 비공개 엔진 소스, API 키·토큰을 등록하지 않습니다. 저장소 공개 여부와 기존 제품의 소유권·사용권은 이번 작업에서 변경하지 않습니다.
