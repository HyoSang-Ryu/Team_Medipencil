# KIDE v4 적용 범위 · 2026-10-13

사용자가 제공한 API-v4.md, teammate-kit v4의 API.md, trend_api_expected.json의 구조를 참고했다. 새 전체 명세 확정이 아니다. 2024년 샘플과 원본 데이터는 DB/Git에 반입하지 않았다.

## 사용 흐름

직원 음성 또는 독립 합성 전사문 → 브라우저 직접 외부 API 호출 → v4 초안 DB 저장 → 5영역 간호기록/발화 근거/누락 질문/추세 지표 확인 → 보호자 연결과 공유 범위 확인 → 확인·저장/발송. 미확인 질문은 전사문을 보완해 재생성하거나 미확인 상태로 유지한다. AI의 send/status 값은 실제 승인이나 발송이 아니다.

선택 입력인 '독립 합성 시연 정보'에서 이름/발화 이름/날짜/보호자/범위/알림 선호/민감약 정보를 직접 적용할 수 있다. 시스템의 제공 환자 자료는 자동 첨부하지 않는다. 실제 EMR 및 제공자료의 외부 전송 허용은 별도이며 본 적용에 포함하지 않는다. 현재 화면은 대상자당 보호자 1명 흐름이다.

## 결과와 권한

- v4 배열형 nursing_note, charting/source_ko, missing_questions, family_notices, metrics를 보존한다. 기존 v3 기록도 읽을 수 있다.
- 한국어 설명과 핀란드어 기록을 함께 검토한다. API가 주지 않는 영어 번역은 만들지 않는다.
- source_ko=null은 '근거 없음'으로 표시하며 근거를 꾸며 채우지 않는다.
- 가족 발송 후보는 수신 계정과 정확한 전사 근거를 직원이 연결해야 한다. send=false는 공유할 수 없다. API 보호자 이름을 로그인 계정으로 자동 추정하지 않는다.
- 현재 권한/동의 버전, 항목 범위, 명시적 직원 확인을 서버에서 재검사한다. 알려진 민감약 명칭은 가족 문구에서 추가 차단한다. 모든 의미·표현을 자동 검증한다는 의미는 아니다.
- 가족 응답에는 간호기록/지표/전사 원문을 포함하지 않는다. 보호자별 검토된 문구만 제공한다.

## 추세

GET /api/v1/kide/{subject}/trends?start=2026-MM-DD&end=2026-MM-DD 는 직원 전용이다. 앱 DB에서 직원이 승인한 v4 기록만 읽고 날짜별 최신 승인 기록을 사용한다. 최신 기록을 철회하면 이전 기록으로 해당 날짜를 다시 채우지 않는다.

직원 화면에서 3/7/30일 및 마지막 날짜를 선택한다. 수면/수분/야외활동 점 그래프와 식사/기분/통증/투약 상태 표를 제공한다. 미기록=null, 기록된 없음=0/[]를 구분하며 미확인 투약은 taken에 합산하지 않는다. 빈 날짜를 채우거나 수면·기분·활동의 인과관계를 추론하지 않는다. 기분 점수표 현지 검수는 미완료다.

## 검증 경계

독립 합성 fixture로 저장·승인·수신자/범위 차단·철회·추세를 검증한다. 실제 외부 API 호출은 별도 기록한다. 제공 예제 응답을 재생한 결과를 실제 AI 실행으로 보고하지 않는다. 실제 음성의 다국어 정확도, 의료적 의미 및 핀란드어 품질은 별도 검수 대상이다.
