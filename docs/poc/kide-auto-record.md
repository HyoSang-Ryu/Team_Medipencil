# KIDE 대화 종료 → 핀란드어 초안 → 확인·발송

2026-10-13 로컬 PoC 구현. 외부 Round Loop 기록 생성 API를 사용한다. 기본 가족 생활 현황은 유지하고 음성 업무에 연결한다.

## 사용 흐름

1. 직원 로그인 → 음성 기록. 제공 대상자는 KaiLab Round Loop를 선택한다. 기존 Helmi 시연도 같은 KIDE 패널을 제공한다. Local Whisper 경로는 별도로 유지한다.
2. 독립 합성 음성·전사의 외부 처리 확인 후 녹음을 시작한다. 기존 EMR/페르소나 파일·환자 문맥·가족 질문을 외부 요청에 자동 첨부하지 않는다.
3. 의료종사자와 대상자 대화의 실시간 전사를 표시한다. 확정 전사 말미에 `KIDE, 정리해줘`, `키데 정리해 주세요`, `KIDE, summarize`, `KIDE tee yhteenveto`가 나타나면 정지한다. 잠정 partial 문장으로는 종료하지 않는다. 또는 `대화 종료·정리` 버튼을 누른다. 화자 인증/웨이크워드 음성 엔진이 아니라 전사 텍스트 기반 명령이다.
4. 서버의 `done` 후 종료 명령을 제거한 전사를 `/v1/record`에 자동 전송한다. 핀란드어 간호기록9항목·보호자 카드8항목·간호사 확인사항을 로컬 SQLite 초안으로 저장한다. AI가 반환한 상태를 승인 상태로 신뢰하지 않는다.
5. 직원은 원래 전사, 핀란드어 기록, 누락·간호사 경고, 카드별 인용 근거와 공유 범위를 확인·수정한다. 미확인 카드는 발송하지 않는다. 범위는 기본적으로 모두 포함하므로 실제 카드 내용 검토 후 필요한 범위로 좁힌다. 보호자 옆 숫자로 허용된 카드 수를 표시한다.
6. `확인 및 발송` 한 번으로 확정 기록과 선택 보호자별 공유를 저장한다. 보호자는 앱의 핀란드어 카드만 본다. 원문 전체·간호기록 전체는 받지 않는다. 수신자 미선택 시 확인·저장만 한다. 이 버튼은 즉시 앱 내 공개이며 기존18시 정기 발행이나 문자/푸시 발송과 별개다.

## 유지되는 경계

- 보호자 공개에는 사람 확인이 필요하다. 생성 완료만으로 공개하지 않는다.
- `kasitelty=false` 카드는 가족 API에서 제외한다. 각 공개 카드에 비어 있지 않은 텍스트·근거·범위가 있어야 한다. 근거는 원문 부분 문자열과 일치해야 한다. 의미 일치까지 자동 보증하지는 않는다.
- 선택 보호자의 현재 대상자 연결·공유 범위를 검사한다. 공개 카드마다 모든 요구 범위가 허용되어야 한다. 기존 시연은 현재 동의 버전, 제공 대상자는 PoC 공유 revision을 저장하며 이후 변경 시 옛 카드를 숨긴다. 철회 뒤 재허용되어도 옛 카드를 자동 복원하지 않는다.
- 생성 재시도는 동일 요청ID/전사로 재사용한다. 같은 ID의 다른 대상자·전사는 충돌 처리한다. 실패 전사는 보존하고 재시도할 수 있다. 진행 중 요청은 차단하며 서버 중단 후 120초가 지난 생성 작업은 재시도 가능하다. 발송 중복은 새 카드를 만들지 않는다. 공개 후 수정은 차단하고 공유 철회를 제공한다.
- 상태: generating → draft 또는 failed → published → withdrawn. 저장 위치는 데이터루트의 kide.sqlite. 외부 provider 키는 기존 서버 전용 파일만 사용한다. 외부 오류 본문은 노출하지 않는다.

## 검증 결과와 미완료

- API144시험 통과, 웹30시험 통과, typecheck/build/OpenAPI 생성 통과. 자동 전사 종료 이벤트→생성 API 호출, 확인 전 발송 금지의 UI 시험은 **명시적 mock**이다.
- 실제 외부 `/v1/record`: 새 독립 합성 한국어 대화(식사 절반, 오후 산책 계획·아직 미실행)를 입력,5.6초 후 핀란드어9항목·8카드 초안 저장. 종료 명령 제외 확인. 이는 실제 LLM 호출이며 STT 전체 E2E 시험은 아니다.
- 실제 출력에서 원문에 없는 평온한 상태 표현, 식사량의 활력징후 오분류, 말줄임표를 포함한 불일치 인용을 확인했다. 원문 근거 불일치 발송은422로 차단됐다. 독립 합성 시험에 한해 불일치/잘못된 항목을 수정한 후 별도 직원·가족 HTTP 쿠키 세션으로 발송200, 핀란드어4카드 열람, 중복 발송200·중복 없음 확인. 임상적 검수/실제 간호사 승인으로 보고하지 않는다.
- CUA 직원 음성 화면 KIDE 패널·저장 목록·확정 기록 조회 확인. 실제 물리 마이크/음성 종료 명령의 실제 엔진 인식/잡음·모바일 시험은 NOT_RUN. 앞서 확인한 한국어·핀란드어 STT 오인식은 미해결이며 버튼 종료를 함께 제공한다.
- 보호자·직원 확인용 다국어 번역은 아직 연결하지 않았다. 현재 기록·카드 본문은 핀란드어, UI는 기존 ko/en/fi. 제공 API가 번역 규격을 제공하지 않아 번역이 된 것처럼 표시하지 않는다.
- 기존EMR 파일 연계, 자동 임상판단, 실EMR 쓰기, KIDE 카드의18시예약, 외부 푸시/문자, GitHub/성아 배포는 이번 변경에서 미실행이다.
