# Round Loop 실시간 전사 — 로컬 연결

2026-10-13. 사용자 제공 teammate kit v3의 API.md를 참고해 연결했다. 키트의 스크립트는 실행하지 않았다. 이 변경은 로컬 PoC만 대상으로 한다.

## 사용

직원 로그인 → 음성 기록 → 전사 엔진 `KaiLab Round Loop` → 독립 합성 음성 외부 전송 확인 → 실시간 받아쓰기 시작 → 녹음 정지·전사 마무리.

제공 대상자 화면에서는 확정 전사 문장이 편집 가능한 임시 전사란에 들어간다. 기존 `기록 초안으로 복사`와 사람 확인 단계를 거친다. 원래 시연 대상자는 별도 접이식 실시간 전사 패널로 표시한다. 자동 번역·차트 생성·저장·승인·가족 발행은 이 엔진에 새로 연결하지 않았다. 기존 Local Whisper는 기본 선택으로 유지한다.

음성은 외부 엔진으로 전송된다. 제공 EMR/페르소나/기록 파일·환자 문맥은 전송하지 않는다. 독립 합성 시연 발화만 사용한다. 브라우저에서 잠정 문장과 확정 구간을 구분하며, 연결 실패는 완료로 표시하지 않는다. 화면 이탈/세션 종료 시 자원을 해제하고 백그라운드 전환 시 정지한다. 최대 180초, 동시 서버 연결 2개.

## 설정·계약

서버 전용 `~/.config/medipencil/roundloop.json`(0600)에 `base_url`과 `api_key`를 둔다. 키·실제 연결 주소는 저장소/프런트엔드에 넣지 않는다. URL 변경은 이 파일에서 교체한다. 공유 PoC 모드에서는 비활성화한다. 외부 서버의 가용성/보관 정책은 별도 확인 대상이다.

브라우저 → 세션/Origin/CSRF 확인한 일회용 티켓 → 로컬 WebSocket → 외부 WebSocket 구조다. 원문 오류·키 포함 URL은 사용자에게 반환하지 않는다. PCM16 LE mono 16kHz, 약100ms 프레임. `segments`는 전체 교체하며 `partial`은 별도 표시한다. `stop` 이후 `done`을 받아야 완료다. 서버는 파일로 음성/전사를 저장하지 않으며 외부 제공자의 저장 여부를 보증하지 않는다.

v3 문서는 `/v1/stream?key=...`만 정의한다. 언어 지정 매개변수는 문서에 없다. 초기 `language` 매개변수 시험에도 오인식이 발생했고, 최종 코드는 확인되지 않은 매개변수와 언어 선택을 제거했다. 사용자의 3개 언어 지원 설명과 실제 시험 결과를 구분한다. 제공자에게 언어 지정 방식 확인 질문을 남겼다.

## 실제 엔진 시험

` .venv/bin/python tools/dev/verify_roundloop_stt.py --send-synthetic-audio `

macOS say의 설치된 Eddy 음성으로 새 비임상 문장만 생성하고 ffmpeg로 PCM 변환했다. 실제 로컬 HTTP 로그인 → 티켓 → 로컬 WS → 외부 엔진 → 여러 transcript → done을 세 번 수행했다. 기존 자료/사용자 마이크는 사용하지 않았다. 아래 시간은 전송·종료를 포함한 전체 시간이며 개별 구간 지연이나 품질 벤치마크가 아니다.

|발화|입력|최종 결과|전체 시간|
|---|---|---|---|
|한국어|이것은 합성 음성 테스트입니다.|Ei koskaan absoluuttisesti ymmärrä.|6.96초|
|영어|This is a synthetic speech test.|This is a synthetic speech test.|6.15초|
|핀란드어|Tämä on synteettinen puhetesti.|Jeg må undslippe til den puget testi.|5.51초|

연결 및 실제 전사 실행은 확인했다. 영어 한 문장 일치, 한국어·핀란드어 오인식은 미해결이다. 세 언어 품질 통과로 보고하지 않는다. 실제 사람/소음 환경/모바일 마이크/장시간 전사·현지 전문가 검수는 NOT_RUN이다. API 키는 추적 파일 및 프런트엔드 번들 검색 결과 미포함. 공급자 기록 생성 `/v1/record`는 이번 작업 범위에서 미연결이다.
