# 제공 합성자료 로컬 적용 — 2026-10-13

## 적용 범위

사용자가 지정한 out.zip / PERSONAS.md를 로컬 시스템에 적용했다. 원본 자료와 SQLite는 저장소 밖 로컬 실행 디렉터리에만 둔다. 제공 문서는 자료로 읽으며, 문서 안의 제안이나 지시는 프로그램 실행 권한으로 사용하지 않는다.

직원 로그인 → **가족 안내 검토함 → 2026 생활 기록**에서 대상자 2명, 기간 3/7/30일 또는 직접 지정, 수면·수분·야외 활동 그래프, 생활 기록, 진료·사회서비스 기록, 합성 보호자 구성을 조회한다. UI는 한국어/영어/핀란드어이며 기록 원문은 핀란드어 그대로다. 임의 번역·의학적 상태 추론은 하지 않는다.

| 자료 | 2026년 적용 건수 |
|---|---:|
| 생활 기록 | 730 |
| 진료 기록 | 7 |
| 사회서비스 기록 | 63 |
| 합성 보호자 | 8 |

대상자 A/B 각각 생활 기록 365개, 보호자 4명이다. 2024~2025년 기록은 가져오지 않는다. 원래 관찰 날짜를 보존하며 기본 조회 종료일은 핀란드 현지 오늘(2026년 범위 내)이다. 미래 날짜를 직접 선택하면 미래 합성 시나리오임을 표시한다. 수분 단위는 dL→mL로 100배 환산한다. 누락 수치는 0으로 치환하지 않고, 빠진 날짜는 그래프 선으로 연결하지 않는다.

## 출처와 경계

PERSONAS의 출처 설명에 따라 `SUPPLIED_VEIL_DERIVED`로 보수적으로 분류한다. 추가 생성된 생활·가족 정보가 섞여 있어도 전체를 독립 TEAM_SYNTHETIC으로 바꾸지 않는다. 원본 ZIP과 문서의 SHA-256을 저장한다. 문서 원문을 모델에 보내거나 AI를 실행하지 않는다.

기존 시연용 Aino와 같은 이름이라는 이유로 동일인으로 연결하지 않는다. 별도 SQLite의 A/B 키와 원래 식별자를 유지한다. 가족의 공유 범위 텍스트는 참고용이며 실제 계정·동의·발행 권한을 생성하지 않는다. 보호자 API 접근은 차단한다. 공유 서버/Pages 환경에서는 API와 메뉴를 비활성화한다.

아직 연결하지 않은 부분: 제공 자료 기반 AI 요약, 기존 가족 화면·정기 전달, 동의 검토 및 실제 가족 계정 매핑, 음성 기록과의 결합. 이번 적용은 직원용 로컬 데이터 검토 기능이며, 보호자 전달 전체 흐름의 완료를 뜻하지 않는다.

## 실행

저장소 루트에서, 기존 로컬 실행 디렉터리를 지정한다. 아래 경로는 사용하는 환경에 맞게 지정한다.

```sh
PYTHONPATH=apps/api/src .venv/bin/python tools/dev/import_provided_data.py \
  --archive '/path/to/out.zip' \
  --personas '/path/to/PERSONAS.md' \
  --data-root /private/tmp/medipencil-voice-20261013
PYTHONPATH=apps/api/src .venv/bin/python tools/dev/run_demo.py \
  --port 8780 --data-root /private/tmp/medipencil-voice-20261013
```

가져오기는 알려진 ZIP 멤버만 읽으며 압축 경로를 추출하지 않는다. 날짜와 대상자 관계를 검증한 후 별도 SQLite를 원자적으로 교체하므로 재실행 시 중복이 늘지 않는다. 오류가 있으면 기존 DB를 유지한다. 임시 실행 디렉터리는 OS 정리 대상이므로 원본 파일을 보관하고 필요하면 다시 가져온다.

현재 로컬 주소: http://127.0.0.1:8780/staff/review (직원 로그인 필요).

## 2026-10-13 후속: 대상자·보호자 업무 통합

위 초기 적용의 “직원 조회만/보호자 미연결” 상태를 이번 구현으로 갱신한다.

- 직원 화면 상단의 공통 대상자 선택: 제공 A/B 및 기존 독립 시연용 Aino. 제공 대상자를 선택하면 생활 조회·음성·기록 공유·질문·공유 설정이 같은 대상을 유지한다. 서로 다른 출처의 대상자를 합치지 않는다.
- 보호자 로그인: 제공 파일의 8계정과 기존 시연 Liisa 계정. 제공 계정은 해당 A/B 대상자로만 연결된다. 계정 이름은 런타임에서 읽고 공개 소스에 하드코딩하지 않는다.
- 보호자 화면: 서버에서 필터링한 3/7/30/90/365일 생활 기록·그래프·직원 공유 메모·본인의 질문/답변·공유 범위. 미래 기록은 제공하지 않는다. 직원 원문/타 가족 질문은 반환하지 않는다.
- 공유 설정: 일상생활/사회적 활동/건강의 명시적 PoC 설정이다. 실제 동의를 가장하지 않는다. 파일의 조건부 건강 공유를 자동 확대하지 않으며 기본적으로 제외한다. 변경은 revision 충돌 검사 후 저장한다. 현재 설정은 메모·답변 재조회에도 적용한다.
- 직원 기록: 핀란드어 기준 기록과 내용/분류 확인 체크 → 범위가 맞는 보호자 선택 → 실제 DB 저장 및 공유. 선택하지 않으면 직원 기록으로만 남는다. 중복 요청 식별자와 수신자/대상자 검사를 적용한다.
- 질문: 보호자 자신의 질문만 조회, 직원은 선택 대상자 질문에 답변. 답변은 일상생활 범위로 제한하는 직원 확인을 요구하며 해당 공유가 해제되면 답변을 숨긴다. 자유문장의 의미를 자동 분류·검증한 것은 아니다.
- 음성: 기존 마이크 컴포넌트/음성 구간 분할/오프라인 Whisper 프로세스 재사용. 선택 대상자 API에 연결, 합성 녹음 확인과 CSRF 검사, 입력 길이/형식 검사. 임시 전사를 수정하여 기록 초안으로 복사한다. 자동 차팅·번역·LLM 호출은 추가하지 않았다. 제공된 임상 파일 자체를 STT에 보내지 않는다.
- 영속 저장: 기존 demo DB에는 제공 보호자 로그인 actor만 등록한다. 공급 자료는 provided-scenarios.sqlite, 공유 설정/직원메모/질문은 별도 provided-workflow.sqlite에 저장한다. 재가져오기로 업무기록 DB를 덮어쓰지 않는다. 공개/공유 환경에서는 제공 계정과 API가 차단된다.

남은 부분: KIDE 대화형 AI, 자동 다국어 번역과 ①~④ 자동 차팅, 제공 대상자의 정기 발행 스케줄/임상 이벤트 발행은 미구현. 기존 시연에 있던 해당 기능을 제공 자료에서 작동한다고 표시하지 않는다. 이 버전은 수동 확인·공유와 로컬 음성 전사 경로까지 연결한다.
