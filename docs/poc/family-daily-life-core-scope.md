# 과제 2.2 — 가족에게 제공하는 생활 현황: 핵심 범위

결정일: 2026-10-13. 근거: 사용자가 제공한 발표 요약과 후속 지시 ‘음성부분은 2차 기능으로 하고 지금 붙여준 내용이 핵심과제야’.
발표 요약은 사용자 제공 자료이며 공식 원문·데이터 명세·사용 조건을 독립 검증한 것으로 표시하지 않는다. 이 문서는 우선순위 결정이며 전체 제품 명세 확정이나 기능 구현 완료 선언이 아니다.

## 핵심 목적
**가족에게 오늘의 생활을 이해하기 쉽게 알려주고, 확인이 필요한 변화는 돌봄 담당자에게 연결한다.**
동의에 기반한 명확하고 최신인 생활 현황이 제품 중심이다. 식사·복약·움직임·수면뿐 아니라 산책·취미·단체 활동·사회적 참여를 포함한다. 가족의 걱정과 확인 연락 감소, 신뢰와 참여 강화를 목표로 하지만 효과 검증 완료를 주장하지 않는다.

## 1차: 핵심 과제
|영역|구현 방향|
|---|---|
|보호자 모바일 첫 화면|오늘의 생활 요약 → 평소/이전과 달라진 점 → 직원 확인·조치 → 정보 상태 순서|
|입력 자료|제공 가능한 모형 센서·웨어러블 데이터와 허용된 기존 기록. EMR은 배경/관찰 근거 중 하나이며 음성 입력을 전제하지 않음|
|센서 정보|움직임·침대 관련 정보·심박수·수면 등. 실제 제공 스키마와 단위·시간·출처 확인 후 연결|
|일상과 참여|산책·취미·단체 활동은 직접 뒷받침하는 기록으로 표현. 센서 신호에서 참여/기분을 추정하지 않음|
|의미 보존 요약|각 문장에 근거를 연결하고 관찰·진술·추정·계획을 구분. 확인되지 않은 원인과 사유를 만들지 않음|
|변화|동일 의미·단위·비교 기간·데이터 충족 조건을 확인. 변화 사실과 확인된 사유를 분리|
|직원 업무|확인이 필요한 항목·가족 문의 → 담당자 확인 → 확인 내용/조치 기록 → 허용된 가족 안내|
|정보 상태|마지막 관찰/측정/업데이트 시각, 자료 누락·오래된 정보·미확인·담당자 확인 상태 표시|
|공유|보호자별 동의와 현재 권한을 요약·카드·그래프·근거·알림 모두에 적용|
|전달|새 소식·확인 결과를 앱 내 안내 및 기존 정기 전달 흐름에 연결. 외부 문자/푸시는 별도 범위|

첫 화면에서 기록 건수보다 일상을 이해하는 설명을 우선한다. 기록 건수는 건강 점수나 완료율이 아니다. 측정값 그래프는 유효한 데이터가 있을 때 표시하고 누락을 0으로 채우지 않는다.

## 의미 보존 예시
- 움직임 감지 ≠ 산책 참여·산책을 즐김.
- 침대 점유/이탈 신호 ≠ 숙면 여부.
- 기기 추정 수면 시간은 추정으로 표시하며 확정된 수면 상태로 바꾸지 않음.
- 약통 열림 ≠ 실제 복용 확인.
- 활동 참여 ≠ 기분 좋음. 본인 표현이나 별도 관찰 근거가 필요함.
- 측정 누락 ≠ 상태 악화·활동 미실시.
- 과거 기록·계획 ≠ 오늘 실제 수행.

## 2차: 음성 기록과 직원 입력 효율화
모바일 녹음, STT, ①~④ 자동 차팅, 누락 질문, 대화형 보완, 직원용 기록과 가족 안내 동시 생성, 음성 명령은 후속 확장이다. 기존 음성 파일 처리 기능은 보존하되 1차 완성의 선행 조건으로 두지 않는다. 기존 설계 문서는 후속 참고로 유지한다.

- [기존 데이터와 음성 확보 데이터 구분](data-source-and-voice-capture-mapping.md)

## 실행 순서와 검증 기준
1. 센서/웨어러블 제공 자료의 형식·출처·단위·시간·누락 패턴 확인. 미제공 시 독립 합성 모형 데이터로 구분해서 시연.
2. 근거·정보 상태를 포함하는 보호자용 생활 현황 데이터 모델과 모바일 요약 화면.
3. 의미 보존 요약과 비교 가능한 변화 표시; 상충/불명확 내용은 확인 대상으로 연결.
4. 직원 확인·조치와 보호자 안내를 연결; 동의 철회·중복 전달·근거 정정을 검증.
5. 가족이 하루를 이해하는지, 확인 연락/직원 부담에 어떤 변화가 있는지 실제 피드백으로 검토.
6. 이후 음성 차팅 확장.

실제 데이터 원문·유래 통계는 이 문서에 포함하지 않는다. 로컬 제공 자료를 공개 PoC에 자동 적재하지 않는다. 실제 AI 실행, 모의 처리, 미검증을 구분하며 실제 엔진이 없을 때 규칙 기반 시연을 AI 실행으로 표시하지 않는다. 임상 진단·자율 처치 권고·효과 입증은 범위가 아니다.
