# 합성 EMR → 로컬 AI → 보호자 안부

직원 검토 화면의 **합성 EMR → AI 안부 → 보호자 전달**에서 기간(1/3/7/30일)과 보호자를 선택한다. 설치된 로컬 Ollama 모델이 허용된 기록을 항목별 핀란드어 문장으로 종합한다. 원문과 생성 문장을 대조하고 기존 검토 체크 후 발행하면 보호자의 대시보드·상세에 표시된다. 저장된 AI 결과 불러오기로 최신 유효 결과를 다시 열 수 있다.

현재 입력은 코드로 만든 독립 합성 식사·이동·수면 관찰과 야외활동 계획이다. 30일 데이터는 날짜별 변화가 있는 Aino 예시이며, 기존 어머니/부모 네 가지 시나리오 전체를 연결한 것은 아니다. 실제 병원 EMR, 실제 사람 데이터, STT 실행은 포함하지 않는다. AI 모델은 실제로 호출되며 결과의 모델·digest·실행시간을 기록한다. 모의 시험 결과에는 실제 AI 실행을 표시하지 않는다.

## 로컬 실행

기존 로컬 실행 환경에서 아래 환경변수를 적용한다. 모델을 자동 다운로드하거나 외부 서비스로 우회하지 않는다.

```sh
export MEDIPENCIL_LLM_BACKEND=ollama
export MEDIPENCIL_LLM_MODEL=gpt-oss:20b
export MEDIPENCIL_AI_TIMEOUT=240
```

모델 교체는 설치된 모델명으로 환경설정을 바꾸면 된다. 전용 로컬 서버 실행 절차는 기존 실행 안내를 따른다. `MEDIPENCIL_POC=1` 공유 시연 환경은 기존 정책에 따라 모델이 비활성화된다. 따라서 GitHub/공유 서버 배포만으로 이 PC의 모델이 서버에 연결되지는 않는다. 비활성 상태에서는 안내문을 표시하고 생성 버튼을 잠근다.

## 데이터와 검증 경계

- 생성 전 보호자의 현재 동의 범위로 필터링하고, 합성자료 출처만 로컬 모델에 전달한다.
- 장시간 추론은 DB 쓰기 트랜잭션 밖에서 수행한다. 결과 저장 전에 직원/보호자 접근, 동의 버전, 자료 버전과 출처를 다시 확인한다.
- 모델 출력의 구조·숫자·항목/계획 구분을 검사한다. 이 검사는 의미·임상·핀란드어 정확성을 보장하지 않으므로 자유 생성 문장의 직원 검토를 유지한다.
- 실패한 모델 결과를 원문 시연으로 조용히 대체하지 않는다. 실패 코드와 실제 실행 여부를 작업에 남기고 발행물을 만들지 않는다.
- 가족에게 원문 근거를 보여줄 때 생성 문장을 원문이라고 반환하지 않는다. 철회/정정 후 조회도 현재 권한·근거를 검사한다.
- 현재 매일 18시 기능은 기존 확정된 합성 원문 자동전달이다. 이 자유 생성 AI 초안을 자동 승인·정기 발행하는 것으로 변경하지 않았다.

## 검증 명령

```sh
PYTHONPATH=apps/api/src .venv/bin/pytest -q
npm --prefix apps/web run typecheck
npm --prefix apps/web run test:run
NO_PROXY=localhost,127.0.0.1 PYTHONPATH="$PWD/apps/api/src" npm --prefix apps/web run test:e2e
MEDIPENCIL_LLM_BACKEND=ollama MEDIPENCIL_LLM_MODEL=gpt-oss:20b MEDIPENCIL_AI_TIMEOUT=240 NO_PROXY=localhost,127.0.0.1 PYTHONPATH="$PWD/apps/api/src" npm --prefix apps/web run test:e2e:local -- ai-summary.spec.ts
```

일반 API 시험의 모델은 테스트 대역이다. 마지막 명령은 실제 설치 모델과 임시 합성 DB·서로 다른 직원/가족 브라우저를 사용한다. 테스트의 검토 체크는 전달 경로 검증이며 사람의 핀란드어 검수 증빙이 아니다.

## 실제 모델 확인 범위

설치된 llama3.1:8b 및 gpt-oss:20b의 3일 합성 입력으로 실제 모델 실행·DB 초안·발행·별도 가족 조회를 확인했다. gpt-oss:20b 30일 입력도 전달 경로는 실행했으나 긴 날짜 목록의 월 표현이 모호한 결과가 관찰되어 의미·핀란드어 품질 통과로 취급하지 않는다. 단기 시연은 3일을 기본으로 사용하고 모든 생성 문장은 원문 대조 후 발행한다. 이 결과는 임상 성능 검증이 아니다.
