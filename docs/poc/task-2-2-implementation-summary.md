# 과제 2.2 최종 정리 — 데이터 활용과 구현 현황

기준일: 2026-10-13  
성격: 현재까지 논의한 범위와 PoC 상태의 정리. 최종 제품 상세명세 확정·임상 효과 검증을 뜻하지 않는다.  
근거: 사용자 제공 발표 요약, 후속 우선순위 결정, 기존 코드·배포 검증 기록. 공식 과제 원문과 센서 데이터 명세는 별도 확인이 필요하다.

## 1. 서비스 목적과 우선순위

**가족에게 오늘의 생활을 이해하기 쉽게 알려주고, 확인이 필요한 변화는 돌봄 담당자에게 연결한다.**

- 1차 핵심: 동의에 기반한 보호자용 생활 현황. 식사·복약·움직임·수면·산책·취미·사회적 참여를 이해할 수 있게 전달한다.
- 보호자 모바일 첫 화면: 오늘의 생활 요약 → 달라진 점 → 직원 확인·조치 → 최신성·누락·미확인 상태.
- 2차 확장: 모바일 음성 입력, STT, ①~④ 차팅, 누락 질문, 직원 기록과 가족 안내의 동시 생성.
- 가족의 걱정·확인 연락과 직원 부담 감소는 목표이며 아직 검증된 효과가 아니다.

## 2. 제공 데이터 활용 정도

|제공 자료|활용할 부분|활용 한계|
|---|---|---|
|환자 기본정보|대상자 식별·기본 속성|보호자 계정·관계·공개 동의는 별도 설정|
|진료·진단·처치 이력|환자의 과거 상태와 배경 설명|오늘 상태로 대체 불가|
|약물 정보|복약 관련 배경|실제 투여·복용 완료를 뜻하지 않음|
|검사 결과|항목·단위·시점이 확인된 결과 조회·비교|일일 바이탈이 모두 있다고 가정하지 않음|
|사회복지 서비스·돌봄 계획|생활 지원 필요와 서비스 계획|당일 서비스·활동 수행과 구분|
|진료·사회복지 서술문|근거 연결·요약·추출 시험|요양원의 연속 일일 관찰을 대체하지 못함|

**활용 판단:** 배경 이력과 근거 연결 시험에 활용할 수 있으나 ‘오늘 어떻게 지냈는지’를 완성하기에는 부족하다. 로컬 분석은 완료했으며 제공 자료를 서비스에 적재하지 않았다.

제공 안내에 따르면 2024–2026 의료·사회복지 자료는 동일 인물 연결이 가능하다. 2025의 두 영역은 별도 집단이며 연도 코호트 간에도 혼합하지 않는다. 실제 적재 시 원본 코호트·도메인·키를 보존하고 연결 검증을 수행한다. 이 문서에는 원본 기록·개별 식별자·데이터 유래 통계를 포함하지 않는다.

## 3. 확보하거나 만들어야 할 데이터

실제 제공 여부를 먼저 확인하고, 없는 부분은 독립 합성자료로 제작한다. 외부 제공 자료를 변형한 것은 독립 합성자료로 재분류하지 않는다.

|필요 자료|내용|현재 판단|
|---|---|---|
|센서·웨어러블 시계열|움직임, 침대 점유·이탈, 심박수, 수면 추정, 시각·단위|제공 형식·권한·내용 확인 필요|
|당일 생활 관찰|식사·수분, 산책, 취미·단체 활동, 사회적 교류, 실제 복약 확인|핵심 시연용 독립 합성자료 보완 필요|
|직원 확인·조치|확인 상태, 확인된 사유, 수행 조치, 확인자·시각|상태 전이와 연결된 시나리오 필요|
|정보 품질 상태|누락·지연·기기 미수신·오래된 정보·상충|정상 시나리오와 별도 실패 시나리오 필요|
|공유 설정|환자–보호자 관계, 항목별 동의, 전달 주기|기존 PoC 구조 재사용, 테스트 조합 보완|
|검증용 정답|허용되는 요약·금지되는 해석·근거·확인 질문|현지 의미 검수와 함께 제작 필요|
|음성·전사 — 2차|돌봄 발화·전사·차팅 정답·보완 답변|1차 선행 조건에서 제외|

기존 30일 합성 시나리오는 로컬 자료 단계이며, 새 센서 흐름과 통합·검증된 서비스 데이터로 취급하지 않는다. 상세 확보 계획은 [온라인팀 데이터 논의 문서](online-team-data-planning.md)를 따른다.

## 5. 1차에서 구현할 부분

1. 허용된 기존 자료와 센서 모형 데이터를 환자·시간·출처로 연결하는 읽기 어댑터.
2. 식사·수면·움직임·활동을 쉬운 문장으로 보여주는 오늘의 생활 요약.
3. 센서 신호·실제 관찰·추정·계획을 구분하고 문장별 근거를 연결하는 처리.
4. 동일 의미·단위·기간과 충분한 근거가 있는 경우의 변화 비교. 사유는 확인된 경우만 설명.
5. 마지막 업데이트·측정 누락·오래된 자료·미확인 상태 표시.
6. 불확실한 변화 → 담당자 확인·조치 → 보호자 안내의 업무 흐름.
7. 보호자 모바일 화면의 생활 요약 우선 배치와 상세 근거 조회. 직원 모바일 확인 목록.
8. 동의 철회·정정·상충·누락·중복 전달·요약 의미 보존의 통합 검증.

## 6. 2차 확장

모바일 녹음·STT → ① 일상생활 ② 건강 상태 ③ 투약 ④ 심리·사회 차팅 → 조건부 누락 질문 → 추가 답변 → 직원 기록·보호자 안내 동시 생성. 음성은 1차 구현을 지연시키는 전제 조건으로 두지 않는다.

## 7. 반드시 유지할 의미 경계

- 움직임 감지 ≠ 산책 참여·즐거움.
- 침대 점유 ≠ 숙면. 수면 추정은 추정으로 표시.
- 약통 열림·처방 ≠ 실제 복용.
- 서비스 계획 ≠ 활동 수행.
- 기록 누락 ≠ 활동 없음·건강 악화.
- 기록 건수 ≠ 건강 점수·돌봄 완료율.

핵심 과제는 **배경 기록 + 당일 생활 데이터 + 직원 확인**을 연결해 신뢰할 수 있는 오늘의 안부를 만드는 것이다. 효과와 사용성은 실제 팀·현장 피드백으로 검증한다.
