# 기존 데이터와 음성 확보 데이터 구분

> **2026-10-13 우선순위 변경:** 핵심은 과제 2.2의 동의 기반 보호자 생활 현황이다. 아래 음성 차팅/음성 확보 설계는 **2차 확장 참고**이며 1차 구현의 선행 조건이 아니다. [최신 핵심 범위](family-daily-life-core-scope.md)를 우선한다.

작성일: 2026-10-13  
상태: 구현을 위한 검토안. 데이터 적재·실제 EMR 연결·AI 학습·기능 구현 완료를 뜻하지 않는다.  
관련 설계: [모바일 중심 음성 차팅·보호자 안내](mobile-voice-charting-design.md)

## 1. 구분 원칙

**기존 데이터는 환자의 배경과 과거 이력, 음성은 이번 돌봄에서 실제로 관찰·수행한 내용으로 사용한다.** 같은 항목에서도 기존 정보와 신규 관찰을 함께 활용한다.

- ‘적용 가능’은 구조상 활용 가능하다는 뜻이다. 실제 포함 여부와 값의 의미·단위·시점·출처를 확인한 뒤 사용한다.
- 기존 문서의 서술은 현재 상태로 복사하지 않는다. 과거 상태, 계획, 실제 수행을 구분한다.
- 기록에 없는 정보는 ‘없음’, ‘정상’, ‘0’으로 채우지 않고 미확인으로 둔다.
- 음성은 입력 수단이다. 같은 정보를 직접 입력하거나 향후 EMR에서 받을 수도 있다. 이미 확인된 당일 정보가 있으면 중복 질문하지 않는다.
- AI 분류·요약은 후보이며 승인·동의·실제 수행 여부를 AI가 확정하지 않는다.

## 2. 항목별 데이터 확보 구분

| 영역 | 기존 데이터에서 활용할 내용 | 음성 또는 신규 입력으로 확보할 내용 | 처리 시 주의점 |
|---|---|---|---|
| 환자 기본정보 | 환자 식별키, 생년·언어 등 제공된 기본 속성 | 현재 기록 대상 확인 | 기본정보를 매번 말하게 하지 않으며 다른 환자 기록과 섞지 않는다. |
| 진료·질환 이력 | 진료일, 진단, 처치, 기존 진료 기록 | 오늘 새로 관찰한 증상·불편, 환자가 말한 내용 | 과거 진단과 오늘 관찰을 구분한다. |
| ① 식사·수분 | 기존 문서에 명시된 식사 지원 필요·돌봄 계획 | 아침/점심/저녁 섭취량, 스스로 먹었는지, 보조 정도, 수분량·단위 | ‘잘 드셨다’를 임의 비율로 환산하지 않는다. |
| ① 위생·피부 | 기존 문서에 명시된 지원 필요·과거 상태 | 세수·양치·샤워 수행과 보조, 오늘 관찰한 피부 변화·상처 | 관찰과 진단을 구분하고 미관찰을 정상으로 처리하지 않는다. |
| ① 배설 | 기존 기록에 명시된 관련 문제·계획 | 소변·대변 횟수와 상태, 배변 여부, 기저귀 교체 | 관찰 기간과 미확인 여부를 남긴다. |
| ① 이동 | 기존 기록에 명시된 기능 상태·이동 지원 계획 | 실제 이동 거리·시간, 보조기구, 직원 도움, 오늘 관찰한 불안정함·낙상 사건 | 과거 보행기 사용을 오늘 사용한 것으로 추정하지 않는다. |
| ② 바이탈·검사 | 검사 결과와 연결된 진료 정보. 항목·단위·시점이 확인된 값 | 새로 측정한 혈압·맥박·체온·혈당과 측정 시각·단위 | 검사 테이블의 숫자를 종류·단위 확인 없이 바이탈로 표시하지 않는다. |
| ② 통증 | 기존 진료 기록의 통증 이력 | 현재 통증 위치·척도·점수, 처치 내용, 이후 반응 | 척도가 다른 점수를 같은 기준으로 비교하지 않는다. |
| ③ 투약 | 약물명·성분, 시작/종료일 등 제공된 약물 정보 | 실제 투여·복용 시각, 복용 확인·거부·미확인, 필요시 투약 이유·결과 | 약물 목록·처방은 실제 복용 완료의 근거가 아니다. |
| ④ 심리·사회 | 기존 문서에 명시된 생활 배경·지원 계획 | 오늘의 기분·행동, 환자의 표현, 대화·교류, 활동 참여 | 환자의 진술과 직원의 관찰을 구분한다. |
| 일정·서비스 | 예약, 사회복지 서비스 결정·계획 | 실제 방문·서비스 수행 여부, 변경·취소·특이사항 | 예약·계획을 실제 수행 완료로 바꾸지 않는다. |

① 일상생활 능력 및 활동: Toimintakyky ja päivittäiset toiminnot  
② 건강 상태 및 측정: Terveydentila ja mittaukset  
③ 투약 및 약물 처치: Lääkehoito  
④ 심리 및 사회적 상태: Psyykkinen vointi ja sosiaalinen toiminta

## 3. 음성보다 시스템 설정·확인 절차로 확보할 정보

| 정보 | 확보 방법 |
|---|---|
| 보호자 계정·환자와의 관계 | 계정 등록과 대상자 연결 |
| 보호자별 공개 범위·동의 | 동의 관리 화면에서 확인·저장 |
| 음성 녹음 허용 여부 | 별도의 녹음 동의 확인 |
| 직원 권한·담당 환자 | 직원·담당자 설정 |
| 환자별 필수 차팅 항목 | 시설 양식과 돌봄 계획에 따라 설정 |
| 알림 수신자·주기 | 보호자별 전달 설정 |

음성에 ‘가족에게 알려주세요’라는 말이 있어도 그것만으로 공개 권한을 확대하지 않는다. 녹음 동의와 가족 공유 동의는 구분한다.

## 4. 시스템에서 유지할 정보 구분

| 구분 | 보존할 내용 |
|---|---|
| 기존 이력 | 기존 데이터의 값·원문 참조·출처·기록 시점 |
| 이번 관찰 | 음성/직접 입력으로 확보한 값·단위·화자·관찰 시점 |
| AI 제안 | 분류·요약·비교 후보, 근거 참조, 사용 엔진·실행 여부 |
| 직원 확인 | 수정 이력·확정 상태·확인자·확인 시각 |
| 보호자 공개 | 수신자·공개 항목·동의 버전·발행 상태 |

관찰 시점과 시스템 입력 시점은 별도로 관리한다. 정정 전 내용을 덮어쓰지 않고 버전과 근거 관계를 유지한다.

## 5. 차팅과 누락 질문에 적용할 로직

1. 환자와 기록 회차를 선택하고 기존 배경 정보를 불러온다.
2. 시설 양식·환자별 계획·이번 회차 업무를 기준으로 필요한 항목을 정한다.
3. 새 음성/직접 입력을 ①~④로 분류하고 원문 근거를 연결한다.
4. 기존 이력은 참고 정보로 표시한다. 이번 회차의 유효한 정보가 이미 있으면 재질문하지 않는다.
5. 미입력·단위 불명·서로 충돌하는 내용·후속 확인이 필요한 항목만 질문한다.
6. 추가 답변 또는 직원의 미확인/해당 없음/후속 확인 예정 선택을 기록한다.
7. 직원이 확인한 기록에서 공개 범위에 맞는 보호자 안내를 생성·검토한다.

모든 환자에게 모든 측정·질문을 매번 필수로 요구하지 않는다. 단순한 항목 언급과 필수 세부 정보 충족을 구분한다.

### 예시: 약물

기존 약물 정보를 미리 보여주고, 이번 회차의 실제 복용 확인을 받는다. ‘거부하셨다’는 답변을 복용 완료로 처리하지 않는다. 필요시 투약 후 효과를 아직 확인하지 않았다면 후속 확인 예정으로 남긴다.

### 예시: 이동

기존 기록의 보행기 사용은 배경으로 제시한다. 오늘 실제 사용 여부·이동 거리·직원 도움 여부는 새 관찰로 확보한다. 이전의 50m를 오늘 값으로 복사하지 않는다.

## 6. 보호자 화면과 그래프 적용

- 과거 배경 정보와 오늘 새 소식을 구분하고 최근 관찰 시각을 표시한다.
- 식사량·수분량·이동 거리 등은 동일한 의미·단위·기간으로 비교 가능한 경우만 추이로 표시한다.
- 데이터가 없으면 미확인으로 표시하며 0으로 보간하지 않는다.
- 기록 건수 그래프는 건강 점수나 돌봄 완료율이 아니다.
- 환자 상태 비교 설명에는 비교 대상 날짜와 근거를 연결한다.
- 비공개 항목은 그래프·카드·필터·원문 조회에서도 제외한다.

## 7. 적용 순서와 경계

우선 기본정보·진료·약물·검사·서비스 계획을 배경으로 연결하고, ①~④의 당일 수행·관찰 결과를 음성/직접 입력으로 채운다. 향후 EMR에서 당일 관찰값을 받을 수 있게 되면 해당 항목의 중복 질문을 줄인다.

외부 제공 자료와 독립 합성 PoC는 출처를 분리한다. 원본·개별 식별자·데이터 유래 통계는 이 문서에 포함하지 않는다. 로컬 데이터 분석 보고서는 별도 보관하며, 이번 문서 작성은 외부 전송·공개 서비스 적재·모델 학습·실제 EMR 연결의 승인이 아니다.

이 문서는 사용자 대화의 설계 정리다. 실제 음성 인식·항목 추출 정확도, 핀란드어 전문가 검수, 현장 업무 효과는 별도 검증이 필요하다.
