## 1. 목적

[확정 설계안 v1.1](../design/medipencil-final-design-v1.1.md)을 Codex가 구현 가능한 수준의 DB·API·화면·상태·엔진·검증 계약으로 구체화했다. 원래의 5단계 돌봄 루프와 핵심 화면1~5는 유지한다. 새로운 서비스 기획이나 실제 코드 구현을 등록한 것이 아니다.

**이 페이지와 루트 [AGENTS.md](../../AGENTS.md)를 Codex에게 전달하면 된다.** 긴 명세를 한 번에 누락하지 않도록 세 문서로 나누었지만 하나의 개발 기준으로 함께 읽는다.

직접 대조한 기준은 저장소 `9437e5cead05663bc575739301997a75750fef80`의 v1.1과 확정 기록이다. 상위 설계 파일·기존 SVG는 변경하지 않았다. 공식 행사 규정·비공개 회신을 이번 작업에서 새로 검증한 것으로 표시하지 않는다.

## 5. 구현 시작에 관한 중요한 구분

**명세가 준비되었다는 것과 지금 과제 전용 구현을 시작해도 된다는 것은 별개**다. v1.1의 사전 제작 경계를 그대로 적용했다. 현재는 준비 단계이며, 현장 시작 또는 범위를 특정한 주최 측 확인 뒤 허용 작업을 명시하여 C 작업을 시작한다. 상세 기준·현장용 지시문은 03 문서 §2에 있다.

엔진·외부 API·Veil 조건 미결이 모든 작업을 막는 것은 아니다. 허용된 구현 단계에서는 독립 합성자료·직접 입력 경로를 먼저 완성하고 해당 외부 연동만 BLOCKED로 남긴다.

## 6. 완료 판정

문서 상태는 SPEC_READY다. 애플리케이션은 이번에 구현·실행하지 않았고 T-01~T-10은 NOT_RUN이다. 실제 완료는 입력→질문→승인→발행→허용된 답이 DB·API·화면에서 동작하고 관련 테스트·사람 의미 검수 증빙이 생긴 뒤 갱신한다.

GitHub에는 설계와 문서용 독립 합성 예시만 등록했다. Veil 원본·파생물, 실제 입주자 정보·음성, 비공개 엔진, 키·토큰은 포함하지 않는다. 코드 공개·데이터 공개·제품 권리는 별개다.
